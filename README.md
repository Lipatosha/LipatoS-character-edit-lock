# LipatoS - Запрет редактирования персонажа

Модуль для **Foundry Virtual Tabletop** и системы **D&D 5e**, который запрещает обычным игрокам включать режим редактирования карточки персонажа.

Повышение уровня и штатные элементы развития персонажа остаются доступными. **ГМ и Assistant GM** работают без ограничений.

## Версия

**1.0.0**

## Совместимость

- Foundry VTT: **14**
- D&D 5e: **6.0.3**

## Возможности

- скрывает элементы включения режима редактирования у игроков;
- действует только для персонажей типа `character`;
- не ограничивает ГМ;
- автоматически повторно применяет блокировку при обновлении интерфейса листа персонажа;
- не мешает штатному повышению уровня и другим доступным игроку функциям развития персонажа.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-character-edit-lock/main/module.json`
